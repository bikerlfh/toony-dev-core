# Runner Command Execution System

**Date:** 2026-03-05
**Status:** Approved

## Problem

The toony_agent_runner currently only executes tasks via the Claude Agent SDK. The backend needs a way to send direct filesystem and system commands to the runner — independent of Claude tasks — for operations like creating files, moving files, downloading assets, cloning repos, and running scripts.

## Design

### Approach: `commands/` module with registry dict

A new `toony_agent_runner/commands/` package with a static command registry. Each command key maps to an async handler function. The backend sends a key + args, the runner looks it up and executes it.

### File Structure

```
toony_agent_runner/
├── commands/
│   ├── __init__.py        # Exports execute_command, COMMAND_REGISTRY
│   ├── registry.py        # COMMAND_REGISTRY, CommandResult, resolve_safe_path, execute_command
│   ├── filesystem.py      # create_dir, create_file, move_file, rename_file, copy_file
│   ├── download.py        # download_url, download_backend
│   ├── git.py             # git_clone
│   └── scripts.py         # run_script
```

### CommandResult

```python
@dataclass
class CommandResult:
    success: bool
    output: str = ""
    error: str = ""
```

Every handler returns this. Exceptions are caught at the `execute_command` level and converted to `CommandResult(success=False, error=str(exc))`.

### Protocol Messages

**Incoming — `command.execute` (backend → runner):**

```json
{
    "type": "command.execute",
    "command_id": "uuid-123",
    "command_key": "create_file",
    "args": {"path": "src/main.py", "content": "print('hello')"}
}
```

```python
@dataclass
class CommandExecute:
    command_id: str
    command_key: str
    args: dict[str, Any]
```

**Outgoing — `command.result` (runner → backend):**

```json
{
    "type": "command.result",
    "command_id": "uuid-123",
    "success": true,
    "output": "File created: src/main.py"
}
```

```python
@dataclass
class CommandResultMessage:
    command_id: str
    success: bool
    output: str = ""
    error: str = ""
```

The `command_id` (UUID generated by backend) lets the backend correlate results with commands.

### Command Registry

```python
CommandHandler = Callable[[dict, Path], Awaitable[CommandResult]]

COMMAND_REGISTRY: dict[str, CommandHandler] = {
    "create_dir":        filesystem.create_dir,
    "create_file":       filesystem.create_file,
    "move_file":         filesystem.move_file,
    "rename_file":       filesystem.rename_file,
    "copy_file":         filesystem.copy_file,
    "download_url":      download.download_url,
    "download_backend":  download.download_backend,
    "git_clone":         git.git_clone,
    "run_script":        scripts.run_script,
}
```

### Commands and Args

| Key | Args | Description |
|-----|------|-------------|
| `create_dir` | `path` | Create directory with parents (`mkdir -p`) |
| `create_file` | `path`, `content?` | Create empty file or with content |
| `move_file` | `source`, `destination` | Move file or directory |
| `rename_file` | `path`, `new_name` | Rename in same directory |
| `copy_file` | `source`, `destination` | Copy file or directory |
| `download_url` | `url`, `destination` | Download from external URL |
| `download_backend` | `download_url`, `destination` | Download from backend (auth via api_key) |
| `git_clone` | `repo_url`, `destination?` | Git clone inside working_dir |
| `run_script` | `path`, `args?` | Execute .sh/.bash/.py inside sandbox |

### execute_command

```python
async def execute_command(key: str, args: dict, working_dir: Path) -> CommandResult:
    handler = COMMAND_REGISTRY.get(key)
    if handler is None:
        return CommandResult(success=False, error=f"Unknown command: {key}")
    try:
        return await handler(args, working_dir)
    except Exception as exc:
        return CommandResult(success=False, error=str(exc))
```

### Main Loop Integration

Commands dispatch as independent async tasks — they don't block Claude tasks or each other:

```python
elif isinstance(msg, CommandExecute):
    asyncio.create_task(_handle_command(msg, conn, config))
```

```python
async def _handle_command(msg: CommandExecute, conn: BackendConnection, config: RunnerConfig) -> None:
    working_dir = Path(config.claude.working_directory).resolve()
    result = await execute_command(msg.command_key, msg.args, working_dir)
    await conn.send(
        CommandResultMessage(
            command_id=msg.command_id,
            success=result.success,
            output=result.output,
            error=result.error,
        ).to_json()
    )
```

For `download_backend`, `_handle_command` injects `api_key` and `backend_http_url` (ws:// converted to http://) into `args` before calling the handler.

### Sandboxing

All path operations go through `resolve_safe_path`:

```python
def resolve_safe_path(working_dir: Path, relative_path: str) -> Path:
    resolved = (working_dir / relative_path).resolve()
    if not resolved.is_relative_to(working_dir):
        raise ValueError(f"Path escapes sandbox: {relative_path}")
    return resolved
```

- Prevents path traversal (`../../etc/passwd`)
- Follows symlinks before validating (`.resolve()`)
- External URLs (in `download_url`, `download_backend`, `git_clone`) are not path-validated — only the local `destination` is sandboxed
- `run_script`: script must exist inside sandbox, subprocess runs with `cwd=working_dir`, only `.sh`/`.bash`/`.py` extensions allowed
